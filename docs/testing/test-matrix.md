Status values: "Passed (automated)" means the listed tests assert the whole expected result and passed in that run; "Partly covered" means the listed tests passed but assert only part of it, and the uncovered part is stated; "Not covered by an automated test" means nothing in the test suite asserts it. Correction records what was changed when an expected result did not match the code: three expected results were corrected on 2026-11-07 (TM-09 (b), TM-11 (d), and the key set in TM-12), each with the reason in its Correction cell.

Conventions: all endpoints under `/api/v1`; roles refer to the seeded demo accounts; "demo data" means `uv run python -m app.seed --demo` on an empty `factory_sherlock_test` database with `APP_ENV=test`.
