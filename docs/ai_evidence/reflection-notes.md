# Reflection notes

Private working notes for the Week 8 starting-point reflection and the Week 15
final reflection. These are prompts, not finished text. The reflections
themselves must be written by the student in their own words.

## Starting point (Week 8, 250 to 400 words)

- Prior database experience: [courses, SQL used before, any ORM experience]
- Prior application experience: [languages, frameworks, projects]
- Prior AI tool experience: [which tools, for what]
- Expected challenges: [MySQL constraints, transactions, React, testing, time]
- How and why AI will be used: [planning, SQL drafts, tests, documentation]
- How output will be verified: [run against MySQL, tests, EXPLAIN, course notes]
- What I want to learn: [...]
- Support needed: [...]

## Final reflection (Week 15, 500 to 750 words)

- Compare the starting point with what happened.
- One accepted suggestion (candidate: schema design, conversation 1).
- One substantially revised suggestion (candidate: simulation state machine, conversation 2).
- One rejected suggestion (candidate: Alembic downgrade, conversation 3).
- How context and requirements changed the AI output quality.
- Workload impact: what was faster, what was slower because of verification.
- Changes in understanding of SQL and transactions.
- What I would do differently.
